**Customer Ledger Extensions**



A Microsoft Dynamics 365 Business Central AL project created to practice extending existing Business Central functionality using table/page extensions and event subscribers.



**Project Overview**



This project demonstrates how existing Business Central functionality can be customized and extended without directly modifying the original standard objects.



The project focuses on Customer and Customer Ledger Entry related functionality and provides practice with AL extensions and event-driven customization.



**Main Concepts Practiced**



\- Table extensions

\- Page extensions

\- Event subscribers

\- Customer-related data

\- Customer Ledger Entry concepts

\- Working with existing Business Central objects

\- Extending standard functionality

\- Writing business logic through events

* Table Extensions



Table extensions were used to add or customize functionality without changing the original standard table.



This demonstrates the extension-based development approach used in Business Central.



* Page Extensions



Page extensions were used to customize existing Business Central pages and expose additional functionality or information to users.



* Event Subscribers



Event subscribers were used to respond to existing Business Central events and implement additional logic without modifying the original object.



This provides a flexible way to customize standard Business Central functionality.
